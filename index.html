Selected Projects

IndustrialTelemetry.Engine

C# 12 · .NET 8 · PostgreSQL 16 · Docker
Asynchronous telemetry ingestion pipeline and batch execution state machine

Decouples high-frequency HTTP sensor ingestion from database writes using bounded in-memory channels (System.Threading.Channels) and a hosted background worker with micro-batch flushing. Persists time-series records via PostgreSQL Binary COPY (NpgsqlBinaryImporter) with composite indexing on (batch_id, timestamp_utc), enforcing strict batch lifecycle transitions (Scheduled → InProgress → Completed/Aborted) and threshold alarm rules.

ChemFlow.NET

C# 12 · .NET 8 · SignalR · C11 P/Invoke · SQLite
Modular steady-state process and thermodynamic simulation engine

Implements the Peng-Robinson cubic equation of state (analytical Cardano root solver), safeguarded Newton-Raphson Rachford-Rice vapor-liquid equilibrium flash calculations, and a staged multicomponent distillation column (MESH solver via Thomas Algorithm / TDMA and Holland's θ-method). Resolves directed acyclic flowsheets with recycles using Kahn's topological sort and Wegstein acceleration, streaming simulation telemetry over ASP.NET Core SignalR.

ProcessTwin.Py

Python 3.12 · FastAPI · Asyncio · ctypes FFI · WebSockets
Real-time process digital twin and supervisory telemetry service

Bridges asynchronous Python simulation loops to a compiled C11 shared library (libreactorcore.so) via ctypes FFI, achieving a 9.4x batch integration speedup over pure Python with IEEE-754 parity. Simulates 4–20 mA transmitter noise, evaluates automated safety interlocks (IEC 61511 SIS logic), and streams 5 Hz state updates over WebSockets.

ReactorCore.C

C11 · GCC · Shared C-ABI · Makefile
Dynamic chemical reactor ODE solver and native shared library

Zero-dependency C11 numerical engine solving coupled non-linear mass and energy ordinary differential equations (Arrhenius reaction kinetics and jacket heat transfer) via classical 4th-order Runge-Kutta (RK4) function pointers. Uses contiguous workspace pre-allocation to eliminate heap allocations during integration loops and exposes a C-ABI header (reactor_ffi.h) for multi-language FFI consumption.
