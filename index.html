IndustrialTelemetry.Engine

High-Throughput Ingestion, Batch State Machine & Safety Alarms

Enterprise telemetry ingestion engine built with C# 12 and .NET 8 on Clean Architecture. Solves high-frequency ingestion bottlenecks using bounded in-memory channels with backpressure handling and direct zero-allocation PostgreSQL binary streaming.

  • Asynchronous producer-consumer queue via System.Threading.Channels with a hosted background worker.
  • Direct zero-allocation PostgreSQL Binary COPY (NpgsqlBinaryImporter) with composite time-series index.
  • Batch lifecycle state machine (Scheduled → InProgress → Completed/Aborted) with strict audit interlocks.

ChemFlow.NET

Thermodynamic & Process Simulation Engine with Staged Distillation

Modular chemical process and thermodynamic simulation engine built in .NET 8. Features analytical cubic equations of state, stage-by-stage multicomponent distillation columns, and real-time simulation progress streaming over WebSockets.

Industrial digital twin and SCADA platform built with Python 3.12, FastAPI, and Asyncio. Connects directly to native C11 compiled numerical libraries via an FFI bridge, delivering a 9.4x speedup over pure Python while evaluating IEC 61511 safety interlocks.

ReactorCore.C

High-Performance Dynamic ODE Numerical Solver in C11

Continuous stirred-tank reactor (CSTR) dynamic integration engine built in C11 with zero external dependencies. Provides a stable C ABI designed for high-performance multi-language foreign function interop (FFI).

  • Cache-friendly workspace pre-allocation: zero heap allocations (malloc/free) in time-step loops.
  • Classical 4th-Order Runge-Kutta (RK4) integration with non-linear Arrhenius kinetics.
  • Strict verification of O(Δt⁴) numerical convergence and thermal runaway detection.
