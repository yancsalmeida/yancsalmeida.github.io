# yancsalmeida.github.io

Official personal portfolio and software engineering showcase for **Yan Almeida** (`yancsalmeida`).

Live at: **[https://yancsalmeida.github.io/](https://yancsalmeida.github.io/)**

---

### Features

- **Integrated Industrial Ecosystem Architecture:** Interactive visual explorer of the 4 flagship systems (`ReactorCore.C`, `ProcessTwin.Py`, `ChemFlow.NET`, `IndustrialTelemetry.Engine`).
- **Real-Time Dynamic CSTR / RK4 Oscilloscope:** Real-time numerical 4th-order Runge-Kutta simulation in the browser.
- **Automated Test Audit:** 187/187 tests passing across the 5 repositories.
- **Formal ATS-Compliant CVs:** Direct downloads for single-page PDFs in English and Portuguese.
- **Zero Heavy Dependencies:** Built with semantic HTML5, modern CSS3 (custom properties, flex/grid, glassmorphism), and vanilla JavaScript.
- **Automated CI/CD:** Deployed via GitHub Actions to GitHub Pages.
